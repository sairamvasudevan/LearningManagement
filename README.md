# Problem Solving Lab — learning platform

Initial source import for the 100-hour Problem Solving Lab learning platform.

See the complete source tree and setup instructions in this repository. The application is a Next.js 16 + React 19 + TypeScript frontend with Supabase Auth, PostgreSQL, Row Level Security, student and admin portals, and Module 01 course content.

## Status

- Review build source imported.
- Supabase migrations and security tests included; not yet applied to a live project.
- No production deployment has been performed.
- Configure `.env.local` using `.env.example` before local execution.

See the detailed README and SECURITY.md for setup and limitations.
